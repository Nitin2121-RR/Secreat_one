# Do You Love Me? 💕

An interactive and fun website with a playful "Do You Love Me?" question.

## Features

- 💖 Interactive "Yes" and "No" buttons
- 🏃 "No" button moves away when you try to click it
- 🎉 Beautiful celebration with confetti when you click "Yes"
- 🖼️ Image gallery with interactive hover effects
- 📱 Fully responsive design

## Setup Instructions

### Adding Your Images

1. Add your images to the project folder
2. Rename them as:
   - `image1.jpg` - First image
   - `image2.jpg` - Second image

### Deploy to Vercel

1. Install Vercel CLI (if you haven't already):
   ```bash
   npm i -g vercel
   ```

2. Navigate to the project folder in your terminal

3. Run:
   ```bash
   vercel
   ```

4. Follow the prompts to deploy

### Alternative: Deploy via Vercel Website

1. Go to [vercel.com](https://vercel.com)
2. Sign in with your GitHub account
3. Click "Add New Project"
4. Import this folder or push to GitHub first
5. Click "Deploy"

## File Structure

```
├── index.html       # Main HTML file
├── style.css        # Styling and animations
├── script.js        # Interactive functionality
├── image1.jpg       # First image (add this)
├── image2.jpg       # Second image (add this)
├── vercel.json      # Vercel configuration
└── README.md        # This file
```

## Customization

- Edit the text in `index.html` to personalize the messages
- Change colors in `style.css` by modifying the gradient values
- Add more images by adding them to the gallery in `index.html` and creating corresponding CSS

## Technologies Used

- HTML5
- CSS3 (with animations)
- Vanilla JavaScript
- Vercel for deployment
